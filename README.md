# My Task Manager

A small task manager made with HTML, CSS, and JavaScript.

## How to use it

1. Open `index.html` in your browser.
2. Enter a task name and choose a category.
3. Click **Add task**.
4. Use the buttons beside a task to complete, edit, or delete it.

The app saves tasks and your theme choice in your browser.

## Files

- `index.html` — the page content
- `styles.css` — the page design
- `app.js` — task actions and saving

If your browser does not save tasks when you open the file directly, start a local server in this folder with `python -m http.server 8000`, then visit `http://localhost:8000`.
